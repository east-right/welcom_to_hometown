# 리랭크 방법 비교 (정답단위 Recall@15)

collect_info 리랭크 단계에서 **어떤 신호로 순위를 매길 때 정답이 상위 15개 안에
들어오는지**를 전 질문(11개, 정답 23개)에 대해 측정했다. 공정 비교를 위해 임베딩
방식(매장별 스니펫 concat → 매장당 1벡터, facet max-pool)은 통일하고 **앵커만** 바꿨다.

| # | 리랭크 방식 | 신호 | 추가 비용 | Recall@15 |
|---|---|---|---|---|
| 0 | No-rerank (수집순) | 카카오 정확도순 | 0 | 11/23 = 47.8% |
| 1 | 스니펫 히트 수 | 블로그 노출량 | 0 | 11/23 = 47.8% |
| 2 | 키워드 겹침 (lexical) | 쿼리 단어 매칭 | 0 | 15/23 = 65.2% |
| 3 | Raw query cos | 원쿼리 임베딩 | 임베딩 | 17/23 = 73.9% |
| 4 | HyDE single | 가상문서 1개 | +LLM 1콜 | 18/23 = 78.3% |
| 5 | **HyDE multi (채택)** | 3-facet(전통/인기/미디어) | +LLM 1콜 | **20/23 = 87.0%** |

*귀산옥 해물칼국수는 수집 자체 실패(전 방식 공통 미수집) → 실질 상한 22/23.*

## 해석
- 리랭크를 안 하면(0) 47.8% — 카카오 검색순은 맛집 적합도와 무관.
- 스니펫 노출량(1)은 리랭크 없음과 동일 — 노출량 ≠ 적합도.
- 키워드 겹침(2)만으로 65.2%까지 오르나, 표현 차이(우동≠칼국수)에 약함.
- 임베딩 도입(raw cos, 3) 73.9% — 시맨틱이 렉시컬을 이김.
- HyDE(4) 78.3% — "쿼리 임베딩"보다 "이상적 후기 생성 후 임베딩"이 스니펫과 결이 맞음.
- **multi-HyDE(5) 87.0%** — 3개 각도로 프레이밍 편향 제거. single 대비 +8.7%p,
  raw cos 대비 +13.1%p, 리랭크 없음 대비 +39.2%p. 추가 비용은 질문당 facet 생성 1콜뿐.
